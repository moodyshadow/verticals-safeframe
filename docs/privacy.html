Privacy Policy

Last updated: August 31, 2026

This policy covers the data handled by the Daily Overclocked automation tooling that publishes video content to TikTok and other platforms.

What data is accessed

The integration accesses only what TikTok's Content Posting API requires to publish a video to the channel owner's own account:

  • An OAuth access token and refresh token scoped to the owner's own TikTok account
  • Basic account identifiers needed to address API calls (e.g. open ID)
  • The video files, titles, and captions being published — all produced and reviewed by the owner before publishing

What data is not collected

This integration does not collect data from TikTok viewers, does not access any TikTok account other than the owner's own, and does not sell, share, or use any accessed data for advertising or any purpose beyond publishing the owner's own content.

Storage

OAuth tokens are stored locally on the owner's own machine, used solely to authenticate API requests for publishing. They are not transmitted to any third party beyond TikTok's own API.

Retention and deletion

Tokens are retained until the owner revokes the integration's access via TikTok's own account settings, or deletes the local credential file. Revoking access at any time immediately stops the integration from posting.

Changes

This policy may be updated as the project evolves.
